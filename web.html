Preguntas frecuentes

¿Cuánto cuesta una web o una app?

Depende del alcance. Te preparamos un presupuesto cerrado antes de empezar, sin sorpresas.

¿Qué incluye el mantenimiento?

Actualizaciones, copias de seguridad, cambios de contenido y vigilancia para que tu web no se quede atrás.

¿Puedo pedir solo el mantenimiento de una web o app que ya tengo?

Sí. Revisamos tu web o app actual y te proponemos cómo mantenerla al día.

¿Con qué tecnologías trabajáis?

Front-end con HTML, CSS, JavaScript y React; back-end con PHP y Node.js; y bases de datos como MySQL o MongoDB. Si tu web ya usa otra cosa, lo hablamos.

¿Cómo empezamos?

Escríbenos por email o por WhatsApp contando qué necesitas. Te respondemos en 24-48 h.

¿Dónde estáis?

Estamos en Castellar del Vallès (Barcelona). Escríbenos por email o por WhatsApp.
