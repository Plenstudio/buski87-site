# Logo Buski87

- `b87-mark.svg` / `b87-mark-192|512|1024.png`: la marca **B87** (icono, favicon, perfiles).
- `buski87-logo.svg` / `buski87-logo-1200.png`: marca + "Buski87" para fondo oscuro.
- `buski87-logo-fondo-claro.svg` / `...-fondo-claro-1200.png`: versión para fondo claro.
- Los SVG llevan las letras convertidas a trazos (no dependen de ninguna fuente). Tipografía base: Segoe UI Bold.
- Colores: fondo #171936, borde #2c3066, texto #eef0ff, acento #ffb347 (en fondo claro: texto #0f1020 y acento #e07b00).
- Uso: no deformar, no cambiar los colores, dejar un margen libre igual a la mitad del alto del icono y no usarlo por debajo de 16 px.
- Se generó con un script de Python (fontTools + Pillow); el mismo icono es el `favicon.svg` y el `apple-touch-icon.png` de la raíz.
